# CodeAlpha_WorkZen
WORKZEN is a smart project management tool built using HTML, CSS, JavaScript, Node.js, Express.js, and MongoDB. It features project management, Kanban boards, task assignments, team collaboration, real-time notifications, deadline tracking, and productivity monitoring. Developed as Task 3 of the Code Alpha Full Stack Development Internship. 🚀
# 🚀 WORKZEN – Project Management Tool

**Plan Smarter. Collaborate Better. Achieve Together.**

WORKZEN is a smart project management platform that helps teams organize projects, manage tasks, track deadlines, and collaborate efficiently.

## ✨ Features

* 📊 Interactive Dashboard
* 📁 Project Management
* ✅ Task Management
* 🗂️ Drag-and-Drop Kanban Board
* 👥 Team Collaboration
* 🔔 Real-Time Notifications
* ⏰ Deadline Tracking
* 🎯 Focus Mode
* 📈 Productivity Tracking
* 🔐 User Authentication

## 🛠️ Tech Stack

* **Frontend:** HTML, CSS, JavaScript
* **Backend:** Node.js, Express.js
* **Database:** MongoDB
* **Authentication:** JWT, bcryptjs
* **Real-Time Updates:** Socket.IO

## 🎨 Theme

Midnight Navy + Electric Cyan + Violet

## ⚙️ Installation

1. Clone the repository.

2. Install dependencies:

   ```bash
   npm install
   ```

3. Configure your `.env` file with your MongoDB connection string and required secrets.

4. Start the application:

   ```bash
   npm start
   ```

5. Open the local URL configured by your application in your browser.
